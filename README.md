# Hausman Test Service

Веб-сервис для проведения теста Хаусмана, используемого для сравнения оценок моделей с фиксированными эффектами (FE) и случайными эффектами (RE).

Сервис принимает коэффициенты и ковариационные матрицы FE и RE моделей и возвращает статистику теста Хаусмана, p-value, количество степеней свободы и результат проверки гипотезы.

## Технологии

* Python 3.14+
* FastAPI
* Pydantic
* NumPy
* SciPy
* Dishka
* Uvicorn
* pytest
* uv

## Установка

Для управления зависимостями используется `uv`.

Установить зависимости:

```bash
uv sync
```

## Запуск

Запустить приложение:

```bash
uv run uvicorn main:app --reload
```

После запуска сервис будет доступен по адресу:

```text
http://127.0.0.1:8000
```

Интерактивная документация Swagger:

```text
http://127.0.0.1:8000/docs
```

## API

### POST `/hausman`

Выполняет тест Хаусмана на основе коэффициентов и ковариационных матриц FE и RE моделей.

Пример запроса:

```json
{
  "fe_coefficients": [1.2, 2.4, 3.1],
  "re_coefficients": [1.0, 2.0, 3.0],
  "fe_covariance": [
    [0.10, 0.01, 0.00],
    [0.01, 0.20, 0.02],
    [0.00, 0.02, 0.15]
  ],
  "re_covariance": [
    [0.08, 0.01, 0.00],
    [0.01, 0.15, 0.01],
    [0.00, 0.01, 0.10]
  ],
  "alpha": 0.05
}
```

Пример ответа:

```json
{
  "statistic": 5.208333333333295,
  "p_value": 0.15716232375772857,
  "degrees_of_freedom": 3,
  "alpha": 0.05,
  "reject_null": false
}
```

Если матрица разности ковариационных матриц не может быть обращена, сервис возвращает `400 Bad Request`.

## Тест Хаусмана

Тест Хаусмана используется для выбора между моделями с фиксированными эффектами (FE) и случайными эффектами (RE) при анализе панельных данных.

**Нулевая гипотеза (H₀):** RE-оценка является состоятельной и эффективной.

Интерпретация результата:

* `reject_null = false` — недостаточно оснований отвергнуть нулевую гипотезу, RE-модель не отвергается;
* `reject_null = true` — нулевая гипотеза отвергается в пользу FE-модели.

Уровень значимости задаётся параметром `alpha`.
